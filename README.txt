مشروع مشغل وبحث فيديو - Railway Ready

الملفات كلها في نفس المسار:
- main.py
- index.html
- requirements.txt
- README.txt

Railway:
المشروع مصمم ليعمل مع أمر التشغيل:
gunicorn --bind 0.0.0.0:${PORT:-8000} main:app

تشغيل محلي:
pip install -r requirements.txt
python main.py

ثم افتح:
http://127.0.0.1:5000
