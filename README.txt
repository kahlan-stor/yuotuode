# مشروع مشاهدة وبحث فيديو

## التشغيل
1. ثبّت Python.
2. نفّذ:
   pip install -r requirements.txt
3. شغّل:
   python app.py
4. افتح:
   http://127.0.0.1:5000

الواجهة والملفات كلها في جذر المشروع، مع مجلد templates الضروري لـ Flask.

## ملاحظات
- yt-dlp يحتاج إلى تحديث دوري لأن مواقع الفيديو قد تغيّر آلياتها.
- روابط البث المستخرجة مؤقتة.
- الصوت يتم إرجاعه بالصيغة التي يوفرها المصدر، وليس تحويلًا مضمونًا إلى MP3.
- بعض جودات الفيديو تكون مسار فيديو منفصلًا عن الصوت، لذلك قد لا يتوفر كل خيار كمسار تشغيل كامل بدون معالجة/دمج.
